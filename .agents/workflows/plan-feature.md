# Plan a TutorGrid Feature
1. Read AGENTS.md and applicable product/architecture docs.
2. Identify user role and user outcome.
3. List in-scope behavior and explicit out-of-scope behavior.
4. Write acceptance criteria, including permissions, error states and data persistence.
5. Identify API/schema/events/UI changes and dependencies.
6. Propose smallest vertical slice, risks and tests.
7. Ask for approval if product/architecture/scope decision is needed. Do not code until plan is accepted.
