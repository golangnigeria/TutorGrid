# Implement a TutorGrid Feature
1. Confirm accepted plan and feature acceptance criteria.
2. Inspect current code and follow existing patterns.
3. Implement the smallest end-to-end vertical slice.
4. Add/update tests, API contracts, migrations and docs.
5. Run targeted tests, lint, typecheck/build and migration checks relevant to the change.
6. Inspect diff for unrelated edits, tenant/security flaws, placeholders and scope drift.
7. Report changed files, checks/results, known limitations and next task.
